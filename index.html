🎯 What Is This Project?

expo-boilerplate is a complete, professional starting point for building mobile applications. Think of it as a pre-built house with all the rooms, plumbing, and electricity already installed. You just need to add your own furniture (your app's features) and make it your home.

Whether you're creating a business app, a personal project, or a productivity tool, this boilerplate saves you weeks of setup time. It comes with everything you need to build a modern, fast, and reliable mobile application.

✅ Amazing Features Ready to Use

📱 Expo Router

Simple and powerful navigation between screens, just like browsing websites on your phone.

💾 Offline Support

TanStack Query with SQLite cache means your app works even without internet access.

🎨 Beautiful Design

NativeWind brings Tailwind CSS styling to mobile, making your app look polished and professional.

⚡ Lightning Fast

FlashList optimizes performance for smooth scrolling even with thousands of items.

🔧 Smart State Management

Zustand with MMKV storage keeps your app's data organized and persistent.

✨ User-Friendly Feedback

Built-in loading skeletons and toast notifications keep users informed about what's happening.

🚀 Getting Started After Download

After downloading, you'll have a complete mobile app project ready to customize. The project includes many sample screens and components that demonstrate best practices. You can:

  • Explore the sample screens to see working examples of forms, lists, and data display.
  • Test the offline capabilities by turning off your internet connection.

The project uses TypeScript, meaning all code is checked for errors before running, making development safer and more reliable.

📋 What You Need

To use this boilerplate effectively, you'll need:

  • A computer running Windows, macOS, or Linux
  • Node.js (version 18 or later) installed on your computer
  • A code editor like Visual Studio Code (free)
  • Either an Android phone or iPhone for testing, or an emulator

Don't worry if you're new to these tools – they're all free and well-documented. The boilerplate includes helpful comments and guides throughout the code.
